# OpenPAVE v1.6.0 — Quickstart & Docs

**Date:** 2026-09-02 · **Tag:** `v1.6.0`

A documentation and onboarding milestone on top of [`v1.5.0-seam`](v1.5.0-seam.md). No runtime code
changes — this release makes OpenPAVE easy to pick up and clarifies what it is for, ahead of the
v1.7 inference-runtime plugin work.

## Highlights

- **Bilingual Quickstart** — [`docs/quickstart.md`](../quickstart.md) /
  [`docs/quickstart.zh-TW.md`](../quickstart.zh-TW.md): five minutes to what OpenPAVE is, how to run
  it (mock, no hardware), and which doc to read next. Linked from the top of both READMEs and the docs index.
- **Per-config runbooks** — one self-contained runbook per combination under
  [`docs/runbooks/`](../runbooks/) (dgx/radxa × puppypi/rpicam, plus the gesture-control baseline).
- **Redesigned architecture diagram** — `docs/architecture-brain-body.svg` now shows the current
  **pluggable seam** (`raw_zenoh` / `device_connect`, no central router), theme-aware, with
  plain-language transport captions.
- **Doc reorg** — consolidated the architecture docs (archived the superseded `architecture.md` into
  the Platform Specification + Brain-Body Architecture), repositioned `validated-baseline.md` as the
  deep operational reference (newcomers start at the Quickstart), and added a table of contents.
- **Positioning** — the spec now states the inference / application dimension is **domain-general**:
  gesture control is one example demo; the same slot holds VLA policy (SmolVLA + SO-101 arms),
  planners, agents, or an external developer's project.

## Naming

- `run_stage3_demo.sh` → `run_openpave.sh`; the camera configs and runbooks renamed to `rpicam`.

## Compatibility

Docs and tooling only — no change to the runtime, the seam plugin, or the validated matrix from
`v1.5.0-seam`.

## Next

`v1.7` — the `create_inference_runtime` plugin (the fourth dimension), making the application layer
swappable. See the roadmap in `docs/openpave-platform-spec.md`.
